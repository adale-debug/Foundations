# Delta Gymnastics Landing Page

A simple, clean landing page for Delta Gymnastics.

## Live Site

Visit the live site at: [https://adale-debug.github.io/Foundations/](https://adale-debug.github.io/Foundations/)

## Project Structure

```
Foundations App/
├── index.html              # Main landing page
├── css/
│   └── styles.css         # Styling
├── README.md              # This file
└── DEPLOYMENT_INSTRUCTIONS.md  # Guide for deploying to GitHub
```

## Features

- Simple, minimal design
- Fully responsive (works on mobile, tablet, and desktop)
- Fast loading with no dependencies
- Hosted for free on GitHub Pages

## Local Development

To view the site locally, simply open `index.html` in your web browser.

## Technology

- HTML5
- CSS3
- No JavaScript required
- No build process or dependencies

## Deployment

This site is deployed using GitHub Pages. See `DEPLOYMENT_INSTRUCTIONS.md` for detailed steps on how to deploy and update the site.
